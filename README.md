> "I don’t just build ML models—I focus on turning them into practical, deployable AI solutions."

Welcome to the source repository for my interactive AI & Machine Learning Portfolio, showcasing end-to-end computer vision systems, deep learning benchmarks, and deployed AI applications.

## Featured Interactive Projects

- **Real-Time Traffic Sign Detection System** (YOLOv8l, PyTorch, Streamlit, OpenCV)
  - 8-class traffic sign detector with dynamic bounding boxes, 92% mAP@50, and 93% precision.
  - [Traffic-Sign-Detector GitHub](https://github.com/Abdelhaleem1/Traffic-Sign-Detector)

- **Clinical Bone Fracture Diagnosis & Grad-CAM Heatmaps** (ResNet50 vs Custom CNN, TensorFlow/Keras)
  - Binary classification benchmark achieving 99.0% accuracy on clinical radiographs with Grad-CAM visual interpretability.
  - [Kaggle Notebook](https://www.kaggle.com/code/halimdev/bone-fracture-detection)

## Tech Stack & Architecture

- **Frontend**: React 19, TypeScript, Tailwind CSS, Vite
- **Simulators**: HTML5 Canvas (Neural Network simulation), SVG Bounding Box overlay, Grad-CAM visualizer
- **Messaging**: EmailJS direct browser integration with client-side regex format validation
- **Deployment**: GitHub Actions & GitHub Pages (`base: './'`)

## Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/Abdelhaleem1/Portfolio.git
   cd Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure EmailJS (optional):
   Copy `.env.example` to `.env` and insert your EmailJS service credentials.

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```
